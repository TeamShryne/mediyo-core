POST an innertube request. body is merged with the session context. The response body is decoded as JSON.

Source

pub fn fetch_visitor_data(&mut self) -> Result<String>

Fetch a fresh visitorData from YouTube. The value is returned and stored in the session context so subsequent requests carry it.

The endpoint is a POST returning the raw visitor data string.
